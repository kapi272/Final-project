What This Website Is About

Active Deception Meets Sub-Second Autonomous IoT Containment

The Autonomous IoT Cyber Defense System is a unified Security Operations Center (SOC) engineered to protect smart-home and industrial IoT networks—such as smart sensors, actuators, MQTT brokers, and IP/CCTV cameras—without relying on sluggish manual intervention. Instead of waiting passively for production hardware to be breached, the platform embeds an interactive Cowrie SSH/Telnet deception honeypot inside the network perimeter to attract, fingerprint, and neutralize attackers automatically.

Every intrusion signal and telemetry packet flows through a real-time analytics engine into an instant SIEM console, giving operators and learners live visibility into attacker credentials, shell exploit commands, firewall drops, and node isolation events over unidirectional Server-Sent Events (SSE).

1. Honeypot Bait & Telemetry

Cowrie captures unauthorized SSH/Telnet sweeps and brute-force logins while Mosquitto & webhooks ingest sensor status.

2. Sliding-Window Engine

In-memory O(1) rolling queues classify brute-force spikes, port scans, and shell payloads in under 1 ms.

3. Kernel Drop & Quarantine

Injects IPTABLES_DROP rules into IOT_DEFENSE_BLOCKLIST and isolates compromised nodes.

4. Forensic SOC Stream

Streams live IST-timestamped events, threat intel charts, IP dossiers, and multi-format audit exports.
